# Interactive agent builder (future)

The builder begins with the human's problem and current workflow, asks only material questions, checks existing local and public solutions with source and license evidence, then proposes reuse, adaptation, combination, or a new build. It drafts a manifest, skill, capability request, target-host mapping, and evaluations for interactive correction.

The human sees sample input, intended plan, proposed tools, sample output, uncertainties, and exact approval points. A draft remains in the repository. Promotion to a project or `~/.stf/` is a separate reviewed action showing version, changed files, scopes, source licenses, evaluation results, and rollback.

No builder executable or agent creation is part of the repository-foundation milestone. The network hardware in `plan.md` is a future example, not an authorized target.
