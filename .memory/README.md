# Curated memory (future)

Memory holds accepted architecture decisions and verified, reusable lessons. It is not a raw transcript, task trace, secret store, or automatic self-edit channel. Agents may propose entries with evidence; a human or approved curator promotes them after review. Superseded entries remain traceable.

`decisions.md` and `lessons.md` are empty registers at the repository-foundation stage. Each future entry should include date, status, source/evidence, scope, and review attribution. Never place credentials, private user data, or unverified claims here.
