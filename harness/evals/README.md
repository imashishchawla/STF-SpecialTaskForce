# Harness conformance plan

Future deterministic fixtures should cover allowed and denied tools, exact target binding, expired/changed approvals, budget and timeout stops, safe retry with idempotency keys, cancellation of parent and child runs, redaction, trace correlation, and collector failure. A second host adapter must run the same cases before portability is claimed.

This directory currently contains no executable fixtures or results. See the broader [evaluation gates](../../evals/README.md).
