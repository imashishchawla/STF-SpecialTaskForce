# Task history (future)

This directory will hold concise human-readable task summaries after runs exist. A summary records task/run IDs, request, scope, outcome, artifacts, evidence, verification, approvals, and known limits. It must not substitute for the structured trace or contain secrets and raw private payloads.

Use a stable task ID in filenames to avoid collisions. Set retention and review ownership before recording real user tasks. The current repository foundation writes no task history.
