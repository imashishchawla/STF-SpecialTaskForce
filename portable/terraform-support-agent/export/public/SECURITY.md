# Security and privacy

Do not put security reports, credentials, customer data, or personal information
in public issues. Use GitHub's private vulnerability reporting on this repository
if the maintainer has enabled it. If unavailable, contact the maintainer through
an approved private channel before sharing sensitive details. No private reporting
channel is claimed to be enabled by this release.

This preview supports synthetic-case testing only. There is no automatic PII
firewall, encrypted case store, live Terraform execution, or MCP integration.
Redact input before it enters Bob. Follow employer AI/data handling requirements.
The read-only mode is scoped to the release workflow; an IDE operator can change
mode or permissions, so it is not an operating-system security boundary.
