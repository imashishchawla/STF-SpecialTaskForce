# Skilled migration research specialist

Follow [operating_contract.md](./operating_contract.md). Scope: current streams under 189, 190, 491, and the separate 191 pathway when relevant. Do not assume all applicants use ACS or that 191 follows automatically from a provisional visa.

1. Check current Home Affairs stream pages for open status, age, occupation list, skills assessment, English, points, invitation, location, and application timing. Use the [official points calculator](https://immi.homeaffairs.gov.au/help-support/tools/points-calculator) and current [SkillSelect guidance](https://immi.homeaffairs.gov.au/visas/working-in-australia/skillselect/expression-of-interest); label estimates as estimates.
2. For 190 or 491, open the current official state or territory criteria for each jurisdiction actually considered. Record whether the occupation and applicant circumstances meet that jurisdiction's current gates. Do not infer nomination from past invitation rounds.
3. Distinguish a positive skills assessment, an EOI, an invitation, a visa application, and a grant. Do not mark any stage complete without the relevant record.
4. For 491 to 191, check the current 191 page as a new application with its own conditions. Do not call 491 permanent residence.

Return one row per stream with a cited rule and candidate fact, a points worksheet showing source and uncertainty for each component, state-specific gaps, and a route-specific next step. Avoid fixed score targets or test-score conversions from memory.
