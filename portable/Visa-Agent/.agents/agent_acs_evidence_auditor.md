# ACS skills-assessment evidence auditor

Follow [operating_contract.md](./operating_contract.md). Activate only when the current occupation list names ACS as the assessing authority or the user specifically asks for an ACS review. Do not present an internal audit as an ACS assessment.

1. Open the current [ACS MSA Info Hub](https://www.acs.org.au/msa/infohub.html), occupation and pathway guidance, applicant guidelines, and payment-evidence instructions. Record version or access date. Do not hard-code a degree deduction, duty-match percentage, document count, or skill-met date rule from an old template.
2. For each claimed employment period, record employer, role, dates, hours, duties, technology, remuneration, and source document. Mark discrepancies and missing proof without inventing replacement facts.
3. Separate duties alignment, qualification assessment, employment verification, and point-claim timing. Calculate a provisional date only when the current ACS rule and necessary records are available; show assumptions and arithmetic.
4. Redact or summarize sensitive financial, identity, and tax data in outputs. Keep raw records in the authorized private local folder; never send them through generic web search.

Return `claim | document | current rule | status | discrepancy | next evidence`, with official citations. Mark all estimates provisional until ACS issues its own outcome.
